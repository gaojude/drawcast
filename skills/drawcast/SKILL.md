# drawcast

The instructions live in the `drawcast` command, so they always match the latest release. This file
only says where to find them.

1. Run `npx -y drawcast@latest guide` and read all of what it prints. It needs Node.js 22.12 or newer.
   Without a network connection, run `drawcast guide` instead.
2. Follow it. It says which command to run and everything else about making the video. Do not work
   from memory or from an earlier run.
